# E5 · From one e-mail to 38 GB
**Sources:** seven layers: mail, proxy, VPN & MFA, directory, endpoint, network (firewall + DNS), cloud.

The 11-step chain with times and source indices is in [`docs/02-attack-timeline.md`](../../docs/02-attack-timeline.md).
